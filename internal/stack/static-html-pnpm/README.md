# static-html-pnpm

Serves one self-contained HTML mock generated by screenshot-to-code as
`public/index.html` on port 3000, using the [`serve`](https://www.npmjs.com/package/serve)
static server installed with pnpm. Works for every source stack (`html_css`,
`html_tailwind`, `react_tailwind`, `bootstrap`, `vue_tailwind`,
`ionic_tailwind`) because each mock is a single file that loads its libraries
from CDNs.

## Layout

| File | Purpose |
|---|---|
| `template.yaml` | Template metadata (mirrors `../catalog.yaml`); `mock_path` says where the mock goes |
| `public/index.html` | The mock (placeholder in the template) |
| `package.json` / `pnpm-lock.yaml` | pinned `pnpm` (via `packageManager`) and `serve` |
| `Dockerfile` | multi-stage (deps → runtime), non-root, healthcheck |
| `docker-compose.yaml` | joins the system gateway (Traefik) — no host ports |
| `.env.example` | `APP_ID`, `APP_HOST` |

## Run behind the gateway

The system gateway (Traefik, host port **3311**, network `traefik_webgateway`)
comes from the root `docker-compose.yml` of screenshot-to-code and must be up.

```sh
cp .env.example .env          # set APP_ID (DNS label) and APP_HOST
docker compose up -d --build --wait
open "http://$APP_HOST:3311/" # e.g. http://run-20261008-101500-ab12cd34-op1.localhost:3311/
docker compose down --rmi local -v
```

`*.localhost` resolves to 127.0.0.1 in browsers; with curl, pass the host
explicitly: `curl -H "Host: $APP_HOST" http://localhost:3311/`.

The compose project name is `APP_ID`, so each generated option is started and
stopped independently.

## Develop locally (no Docker)

```sh
corepack enable
pnpm install
pnpm start                    # http://localhost:3000/
```

## Test

From the repository root, with the gateway running:

```sh
internal/stack/test-template.sh static-html-pnpm [fixture.html]
```
